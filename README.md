# COS 102 Lab Assessment Code

The codes can be built and run. The built binaries are built for my architecture might not work on another computer so each file should be built on the target PC

Build and run commands for Question 1:
gcc right-triangle.c -o right-triangle -Wall
./right-triangle

gcc right-triangle-optimized.c -o right-triangle-optimized -Wall
./right-triangle-optimized

Build and run commands for Question 2:
g++ palindrome.cpp -o palindrome -std=c++14 -Wall
./palindrome

g++ palindrome-optimized.cpp -o palindrome-optimized -std=c++14 -Wall
./palindrome-optimized
